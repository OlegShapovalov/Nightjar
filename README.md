# Nightjar

Быстрый и минималистичный двухпанельный файловый менеджер на C++, Qt 6 и QML для Linux.

## Возможности
- Двухпанельная навигация с вкладками (Ctrl+T / Ctrl+W)
- Поддержка горячих клавиш Midnight Commander / Total Commander (F3-F8)
- Встроенный просмотрщик файлов, изображений и аудио (F3)
- Групповое переименование с регулярными выражениями и счётчиками (Ctrl+M)
- Глобальный поиск по имени и содержимому файлов (Alt+F7)
- Работа с архивами zip, tar.gz, 7z (Alt+F5 / Alt+F9)
- Подключение к удалённым устройствам через SSH/SFTP (Ctrl+F)
- Встроенная консольная строка и выбор тем оформления

## Зависимости
- Qt 6 (qt6-declarative, qt6-multimedia)
- CMake, Ninja, C++17 компилятор
- sshfs, sshpass (для сетевого подключения)

## Сборка вручную
```bash
cmake -B build -S . -G Ninja
cmake --build build
./build/nightjar
